NAACCR LRI validator

Local syntax checks for one HL7 v2.5.1 ORU_R01 cancer-pathology message, with an optional SEER registry-content check.

Privacy: Syntax validation is offline. The optional registry-content check sends only the codes and reference identifiers listed before you run it, never the full message or direct identifiers. Those codes are sensitive clinical metadata. The SEER key stays in memory in this tab, and no browser storage is used.

Message input
